# AibbyScopeDT LEXIDE-Ω用ソースツリー
これはAibbyScopeをデータ・テクノ製の評価ボードDT-EBML63Q2557向けに移植したプログラムです。

## ビルド環境
* LEXIDE-Ω Version: 2.1.0 
* ARM.CMSIS: 6.3.0、6.x系なら使用可能

## 対象ボード
* (株)データ・テクノ製 DT-EBML63Q2557

## 使用上の留意事項
#### ● 電源ボタンを押すと動作を始めます。電源をOFFする機能はありません。
#### ● 動作表示はLEDの点灯のみ、液晶には何も表示しません。
#### ● アナログ入力専用です。緑色のアナログ入力コネクタから信号を入力してください。
#### ● ゲイン変更DIPSWが使用できます。
#### ● 適切にジャンパを設定してください
| ジャンパピン番号 | 使用条件 |
|-|-|
| JP1, JP3, JP6, JP8, JP10 | 不問 |
| JP2 | 必ず外す |
| JP4 | 必ず取り付ける |
| JP5, JP9 | 必要な場合に取り付け ※1 |
| JP7 | DC信号を入力する場合に取り付ける<br>JP5とJP7は排他利用になります |

## ※1：JP5・JP9取り付け条件
#### ● ジャンパを外すもの
PCなどのオーディオ機器  
DC信号を出力する機器  
ダイナミックマイク・24V以下の耐圧のエレクトレットコンデンサーマイク(外部のマイクアンプが必要)

#### ● ジャンパを取り付けるもの  
24V電圧に耐えられるエレクトレットコンデンサーマイク  
信号線を使って電源電圧を供給するタイプのIEPE振動センサー  
圧電素子・ピエゾ素子・圧電サウンダ
